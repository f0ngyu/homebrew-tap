# Shots

Shots 是一个 macOS 菜单栏截图工具：框选截图、标注、打码、识别文字、滚动长截图、贴图。截图和文字识别都在本机完成，不联网。

## 安装

```sh
brew install --cask f0ngyu/tap/shots
```

要求 macOS 14 或以上，Apple Silicon。

## 升级

```sh
brew update && brew upgrade --cask f0ngyu/tap/shots
```

应用没有内置自动更新。历史版本和更新内容见 [Releases](https://github.com/f0ngyu/homebrew-tap/releases)。

## 安装前请了解

- 这是个人项目，源码没有公开，这个仓库只放安装包和 Homebrew 配置。
- 应用使用自签名证书，**没有经过 Apple 公证**。安装时 Cask 会去掉 macOS 的隔离标记，也就是跳过 Gatekeeper 检查，请确认你信任这个来源。
- 应用需要「屏幕录制」权限才能截图。第一次截图时按提示授权，然后重启应用。
- 界面只有中文。

## 使用

Shots 只显示在菜单栏，没有 Dock 图标。

| 操作 | 默认快捷键 |
|---|---|
| 截图 | `⇧⌘A` |
| 截取文字（框选后直接复制文字） | `⇧⌘2` |
| 退出、取消 | `Esc` |

快捷键都可以在菜单栏图标的「设置…」里修改。

- **截图**：拖拽框选后可以调整选框，回车或双击确认；单击直接截光标下的窗口。选区支持固定比例、圆角矩形、圆形、椭圆，以及滚动长截图。
- **截完**：自动复制到剪贴板，打开标注窗口；也可以在设置里改成弹出缩略图。
- **标注**：矩形、椭圆、直线、箭头、画笔、荧光笔、文字、序号、聚光灯、裁剪、取色器。
- **打码**：马赛克和模糊；「自动打码」用系统的 Vision 在本机找出手机号、邮箱、密钥、人脸、二维码等，逐个确认后再打。
- **文字**：在截图上像选网页文字一样选中并复制。
- **背景**：把截图放到渐变、图片或当前壁纸上，可调边距、圆角、阴影和比例。
- **贴图**：把截图钉在屏幕最上层，可以拖动和缩放。
- **历史**：菜单栏「最近截图」可以重新打开最近的截图继续编辑。

## 隐私

截图、标注和文字识别全部在本机完成，应用不联网，也不收集数据。设置和截图历史保存在 `~/Library/Application Support/Shots`，日志在 `~/Library/Logs/Shots`，日志不包含截图内容和识别出的文字。

## 卸载

```sh
brew uninstall --cask shots
```

连同设置、截图历史和日志一起删除：

```sh
brew uninstall --zap --cask shots
```

系统设置里的「屏幕录制」授权需要手动移除。
